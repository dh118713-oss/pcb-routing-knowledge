# 按目标选择规则的合成示例

这里的板、网表、参考设计和层叠均为合成输入，不是实际PCB或已核验射频设计。profile中的provenance指向本页，说明这些值来自演示设定；不表示读过某块板的实际BOM/铜形。

- `U1:RF_P-to-matching`：假设CC2652R、RGZ-VQFN48封装、BLE、2402–2480MHz。代码中明示的 `synthetic-*` 参考设计/层叠/天线和返回记录均未做物理验证。候选CC2652R条目应匹配；CC1310条目应排除。
- `U2:AIN-to-sensor`：在同一 `synthetic-mixed-r1` 合成板上，角色为analog_input。它可以获得通用回流分析候选，不应获得U1的RF、DDR、CAN或装配实例要求。未提供完整ADC型号，不能据此产生ADC精度或布局通过结论。
- `unknown-radio`：只有RF角色和2400–2480MHz范围，没有器件、协议、封装。应返回needs_input或由已知冲突排除，不能猜为Wi-Fi/BLE，也不能猜为4G。

所有值都可在对应JSON逐字段复查；未给出的输入保持缺失。测试只证明筛选语义，不能证明任何真实电路设计正确。正式使用时将这些事实替换为从当前BOM、网表、器件手册、设计配置和工程快照提取的证据。
