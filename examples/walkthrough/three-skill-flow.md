# 三 Skill 初学者流程

这个流程适合第一块低速 MCU 板：一个精确型号的 MCU、一个电源输入和稳压器、LED、按键、UART 调试、I2C 传感器、SWD，以及普通两层或四层工艺。示例描述调用顺序，不伪造真实芯片引脚、EDA 结果或制板结论。

## 1. 原理图设计

向原理图 skill 提供：

- 完整 MCU 订货号和封装；
- 输入电压、目标电源轨和大致电流预算；
- LED、按键、UART、I2C 传感器、SWD 等功能；
- 连接器方向、尺寸限制和需要预留的测试点。

原理图 skill 联网读取官方产品页、数据手册、参考手册、封装引脚表和硬件设计指南，规划电源、去耦、复位、启动配置、时钟、调试和外设复用，输出 `design-intent.json`。`POWER`、`VCC`、`TX`、`SDA` 等名称只作为线索；分类必须结合器件端点和证据。资料缺失、引脚冲突或电压域不清时，状态为 `needs_input`。

## 2. PCB 约束

用户确认设计意图后，将原理图 revision、网表、BOM、层叠、铜厚、制造能力、工作电流和板框交给 PCB skill。它先按 [设计复杂度分级](../../references/complexity-levels.md) 判定是否能走初学者自动辅助流程，再生成电源/返回路径、去耦位置、接口保护、布线优先级、测试点和 DFM 检查项。

对于缺少层叠、边沿、电流或回流信息的项目，输出草案和待补资料；不能凭板层数或网络名称给出确定阻抗、线宽或温升结论。

## 3. EasyEDA 执行

EasyEDA skill 读取已批准的设计意图和约束，确认当前工程、文档类型和目标原理图/PCB 页面，再按操作计划绘制和修改。每个关键操作后回读对象、网络和规则，保存工程并运行 ERC/DRC。执行结果必须记录 `schematic_revision`、`board_revision`、操作状态和能力缺口；API 成功不等于电气设计正确。

## 4. 打样前检查

确认电源极性和最大电流、去耦和复位、启动脚、调试口、接口方向、外部保护、板框/安装孔、ERC、DRC、Gerber、坐标文件、BOM 和测试点。把不能由工具证明的事项保留为人工检查或实测任务。完成简单板并不意味着高压、射频、高速存储、复杂电源或量产认证可以沿用同一自动流程。
