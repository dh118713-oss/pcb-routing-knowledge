# 研究与证据治理

本库把可以追溯的工程资料转换为有适用条件、可执行、可检查的规则。书目数量不是学习完成度，DRC 通过也不是热、信号完整性或 EMC 性能证明。研究结果必须说明读到了什么、未读到什么、由谁在什么条件下验证过。

## 来源状态与引用边界

来源登记位于 `sources/`，规则通过稳定的来源 ID 关联。`checked_on` 是本次核查日期，不是出版日期，也不保证链接永久有效。

| 状态 | 可以声称的内容 | 使用限制 |
| --- | --- | --- |
| `unverified` | 找到了候选线索 | 不能作为工程规则证据；说明访问失败或元数据缺口 |
| `metadata_verified` | 已从原始发布者核验标题、作者、版本等 | `supports` 必须为空；目录、摘要、营销简介不等于正文已读 |
| `partial_content_reviewed` | 已阅读明确列出的章节、节选或预览 | `reviewed_sections` 写精确位置，只能支持这些内容确实支撑的结论 |
| `content_reviewed` | 已阅读所登记原始文献的完整内容，并核查拟引用结论的上下文 | 仍需记录模型、实验条件和局限；读完也不等于本地复现实验 |

书籍只阅读几个章节必须使用 `partial_content_reviewed`。官方预览的封面和目录只能核验书目；若预览还含正文首面，可登记具体章节，不能推断未公开的表格。网页中以图片呈现的公式、标注、脚注未查看时，明确排除这些内容，不使用 OCR 缺失的数字建立规则。

获取资料优先使用标准组织、出版社、器件厂商、接口组织、期刊或作者合法公开页。记录稳定 URL、版本、ISBN/DOI（确实核验才填写）及原始核查证据。多家网站转载同一论文不算多个独立证据来源。打不开的全文不得依靠标题、搜索摘要或模型记忆补写实验结果。

## 合法访问与原创整理

仓库保存书目信息、必要的短引用定位和自己编写的工程摘要、规则及计算实现，不保存未经许可的书籍、付费标准全文或整章复制。出版社公开样章可以用于阅读核对，但公开可读不代表可以重新分发。遵守原始许可；若资料需要购买、机构访问或用户提供合法副本，记录获取需求，不使用盗版镜像补齐。

引用按章节、页码、表/图编号或可定位的网络分页列明；实体页码未核验就写“实体页码未核验”，不能把网页分页当成纸书页码。所有工程摘要用自己的语言表达，保留限制条件，不将原文重写到足以代替原书的程度。

## 处理规则冲突

不要按“书籍永远高于应用笔记”或“新资料永远取代旧资料”直接选边。先比较争议是否来自不同工作条件：器件型号及封装、接口版本与边沿、网络参考电位、层叠和材料、布局几何、电流波形、温升环境、测量带宽、终端条件、制造过程与产品合规范围。

1. 先确定项目合同、目标性能、适用产品规范、法定要求与制造约束；分别记录其效力范围。通用指南不能降低已确认适用的安全或产品规范要求。
2. 核对具体器件 datasheet、勘误、参考设计与接口规范的版本和适用条件。专用要求通常比不针对该器件的经验更直接，但仍须与板上实际工作条件相符。
3. 对剩余工程方案，用可复核的物理分析、适用的模型、仿真和测量比较。一个应用笔记示例或某本书的一张图不能自动覆盖所有层叠和封装。
4. 写明冲突、适用条件差异、采用方案、被舍弃方案和证据理由。不能消解时，把相关结论标记为待核验，暂停依赖该结论的自动定值；不影响的独立工作可以继续。

不存在“通过换个来源就可忽略物理矛盾”的解决方法。额定电流未知、绝缘条件未知、接口约束未知时，不能让常用默认值伪装成已验证输入。

## 从资料到新规则

一条可执行规则至少包括稳定 ID、原始依据及精确位置、所解决的问题、适用与不适用条件、必需输入及单位、工程动作、计算/判定方法、通过标准、无法检查时的处理，以及修订记录。

对数值额外保存推导或查表路径、原始图表条件、单位换算、插值范围、假设与裕量。不得从一个线宽例子推广出“所有电源至少 X mm”，也不得将“图中电容靠近引脚”擅自数字化成没有出处的距离阈值。

规则执行强度和证据成熟度分开记录：

- **执行强度**：`必须` 用于已确认适用的硬约束或不可违反的连通关系；`建议` 用于带条件的设计优化；`启发` 仅用于候选排序，不能单独生成硬 DRC 数字。
- **证据成熟度**：`候选` 尚未核查正文；`已核读` 已确认来源和条件；`已复核` 已有独立推导、审查或复现；`项目已验证` 在指定板型、版本和测试条件下通过验证。每次升级都要留下依据。

本库的 BAS-001/BAS-002 属于“已核读”的定性工程建议，连通性禁止短路的检查属于必须满足的电路约束；它们尚不是本地实板测量结论。几何检查通过不能把成熟度自动升级成“项目已验证”。

论文结论须保留样品、材料、层叠、频率、电流、环境、边界条件、方法、比较基线和误差。仿真图不是实測；单一样板改善不证明所有 PCB 均改善；“3W”“20H”等经验只在找到相应原文和适用前提后才能作为启发，不得作为普适保证。

## 案例与验证闭环

外部发布案例和本地验证记录分开管理：

- **外部案例**记录原作者、来源、板结构、器件版本、方法、结果和可获得的数据；只能写“作者报告”，不能写“我们实测”。
- **本地验证**记录本地工程版本、Gerber/网表或模型版本、仪器或求解器版本、夹具、探头、校准与带宽、负载和环境、验收阈值、原始数据位置及失败项。

验证输出明确区分规则审查、几何检查、DRC、连通性检查、仿真、样板实测及产品合规测试。检查器拿不到网络、实际铜形、参考平面或层叠时应输出未验证，不能仅凭截图“看起来有地”判定回流可靠。修正后的工程必须重新检查受影响项目；保留失败案例，避免只收录成功样例造成偏差。

## 版本管理和 2026-09-23 核查快照

每次发布记录 skill、规则和来源版本。标准更新、器件勘误、接口变更、制造能力变化、发现反例或实测失败均触发相关规则复查。旧记录保留 ID 和历史，不覆盖旧版本后继续声称旧板已按新版通过。没有进行实际核查时不得自动刷新 `checked_on`。

本次从 [IPC 官方版本表](https://www.electronics.org/ipc-document-revision-table) 核验得到：

| 来源 | 核查到的版本/维护信息 | 本库处理 |
| --- | --- | --- |
| IPC-2152 | 原版 2009-08，`No Longer Maintained` | 可作为已注明版本的历史技术依据候选，未获取完整载流图表，不实现或宣称已符合该标准的载流计算 |
| IPC-2141 | Rev A，2004-03，`No Longer Maintained` | 只读公开预览；不把其目录当作阻抗公式证据 |
| IPC-2251 | 原版 2003，`No Longer Maintained` | 预览页脚写 2003-11，版本表写 2003-12；显式保留该月份差异 |
| IPC-2221 | Rev C，2023-12 | 已核验版本；Rev C 正文未取得，不能借用 Rev B 预览冒充当前条文 |
| IPC-2222 | Rev B，2020-10 | 已核验版本；Rev B 正文未取得，不能借用 Rev A 预览冒充当前条文 |

“不再维护”不自动等于所有物理内容失效，也不代表它足以覆盖当前产品的合规要求。应用时必须确认选用版本、技术适用性和项目接受条件。

[IEC 60664-1:2020 官方页](https://webstore.iec.ch/en/publication/59671) 显示基础版为 Edition 3.0，日期 2020-05-26，并注明包含 2020-10 勘误；该页面已展示 `IEC 60664-1:2020+AMD1:2025 CSV`。本库仅登记已核验的 2020 基础版元数据和该修订提示，未取得基础版或 2025 修订的安全距离表，不能把基础版称为最新完整版本，更不能据网页简介出具安全间距或认证结论。
