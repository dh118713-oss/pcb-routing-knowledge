# 电路域选择矩阵

PCB 不是一种“通用布线问题”。先按原理图、器件型号、边沿/频率、电流回路和外部连接把网络分域，再加载对应规则。一个网络可以同时属于多个域（例如带高速边沿的电源控制线、带隔离边界的 CAN、带射频谐波的时钟），应合并约束并记录冲突。

本表是选择专题的入口，不是协议标准的替代物。接口的最终电压、阻抗、偏斜、共模、爬电、电气间隙和保护等级，必须来自当前协议版本、器件硬件指南、产品标准、制造能力及项目要求。没有读到对应规范正文时，检查为 `status=unknown`，可附 `reason_code=needs_input`。下列分域输入清单用于发起研究；只有链接专题中有实际来源支持的规则才属于已核读能力。

## 1. 先识别网络角色

| 角色 | 识别信号 | 先问的工程问题 | 默认审查入口 |
|---|---|---|---|
| 功率/回流 | VIN、VOUT、PGND、负载电源、MOSFET/电感/分流器 | 连续/峰值/RMS 电流、瞬态、温升、压降、返回路径是什么？ | [电源](power.md)、[计算边界](../calculation-notes.md) |
| 高速数字 | 高边沿 GPIO、时钟、DDR、SerDes、USB、以太网 | 目标阻抗、边沿、电长度、组内/组间偏斜、参考层和过孔模型是什么？ | [高速与RF](high-speed-rf.md)、[多层板架构](multilayer-architecture.md) |
| 低速数字/控制 | I²C、SPI、UART、GPIO、复位、JTAG/SWD | 是否有长线、外部连接、上拉、边沿过快或易受扰对象？ | [模拟与EMC](analog-emc.md)、接口资料 |
| 模拟/精密 | ADC、DAC、运放、基准、传感器、低电平测量 | 参考电流、输入阻抗、噪声/漂移、屏蔽和采样回路在哪里？ | [模拟与EMC](analog-emc.md) |
| 混合信号 | ADC/DAC旁数字接口、时钟、基准和模拟前端共板 | 电流回路如何分开/汇合？参考平面是否连续？是否存在误导性“割地”要求？ | [模拟与EMC](analog-emc.md)、[基础回流](foundations.md) |
| RF/微波 | 天线、匹配、滤波、PA/LNA、晶振/本振 | 频段、阻抗、参考层、封装/连接器/天线环境、调谐方法是什么？ | [高速与RF](high-speed-rf.md) |
| 外部总线/线缆 | CAN、RS-485、以太网、USB、HDMI、连接器 | 保护器件、机壳/屏蔽、共模回流、线缆和ESD/EMC测试是什么？ | [模拟与EMC](analog-emc.md)、[高速与RF](high-speed-rf.md) |
| 隔离/高压 | 市电、DC/DC隔离、数字隔离器、继电器、光耦 | 工作电压、瞬态、污染等级、材料组别、海拔、爬电/电气间隙和隔离域是什么？ | 项目安规/产品标准；缺资料不得自动定值 |
| 热/机械耦合 | 功率器件、散热器、铜柱、连接器、外壳 | 热路径是否经过铜层/过孔/结构件？机械导体是否成为EMC结构？ | [电源](power.md)、论文研究、制造资料 |

## 2. 各领域的最小输入

### 数字与存储器（MCU/FPGA/DDR/LPDDR）

已核读通用入口：`HS-001..004`、`BAS-001..002`；[接口专题](interfaces-memory-isolation.md)的 `INT-002..004` 只覆盖所列 KeyStone DDR3 指南条件。以下DDR/FPGA输入清单不等于已取得各代产品规范或已实现时序验证器；必须补齐目标器件资料后形成具体约束。

- 必须提供器件型号/封装、内存代际和接口规范版本、I/O 电压、最快边沿、时钟与数据组定义、拓扑、端接、封装/连接器延迟、层叠和目标偏斜。
- 不能按“时钟频率低”将网络降级为低速；不能仅凭“同组等长”证明 setup/hold、阻抗、回流和过孔模式转换满足要求。
- DDR/LPDDR 的字节组、地址/命令组、时钟和控制组需按适用器件指南定义的拓扑和偏斜预算分别检查。没有该指南和层叠求解结果时，输出约束草案，不生成固定长度或线宽。
- FPGA 高速 I/O 还要将封装 pin escape、bank 电压、参考电压和电源噪声纳入；盲目蛇形可能增加串扰和局部阻抗变化。

### USB、以太网、CAN、RS-485 和其他外部接口

已核读通用入口：`HS-001..005`、`HS-007`、`ANA-004/006`；[接口专题](interfaces-memory-isolation.md)包含RS-485、CAN与数字隔离的特定指南。具体接口能力还要看资料的阅读范围，不能从通用入口推导所有协议版本均已覆盖。

- 识别连接器入口、保护器件、磁性器件/隔离器、共模路径和机壳/屏蔽连接。保护器件靠近入口只是候选原则，最终需按器件寄生、协议通道和 ESD/EMC 结构验证。
- USB、以太网等通道应按实际模式、器件与接口要求确定需要控制的阻抗，并以真实层叠评估截面；连接器、适用的磁性器件、过孔、AC耦合焊盘及测试点属于通道的一部分。
- CAN/RS-485 不能只检查差分对称；终端、电缆、共模范围、保护钳位、隔离边界和回流路径决定系统行为。长线/外部端口必须有浪涌/ESD/共模审查输入。
- 缺少外部线缆、机壳和测试等级时，允许完成板内几何检查，但不能给出整机 EMC/ESD 通过结论。

### 模拟、传感器与混合信号

已核读通用入口：`ANA-001..005`、`PWR-005`。热电偶、应变桥等应用目前只列输入清单，需补读目标前端与传感器资料，不据本表保证精度。

- 先标出高阻节点、基准、采样回路、回流、屏蔽和时钟/开关噪声源；按电流回路决定布局与汇合点，不按“模拟地永远切开”自动分割。
- ADC/DAC 要把参考源、采样电容、驱动稳定性、数字返回、时钟边沿和电源去耦同时审查。网络名相同不证明采样点或返回路径正确。
- 传感器/热电偶/应变桥等低电平入口要提供线缆、连接器、保护、偏置、滤波、漏电和环境输入；只给原理图不能证明噪声、热电势或湿度可靠性。

### 射频、晶振和时钟

已核读入口：`HS-006`、`ANA-005` 及芯片相关 `OSS-001`；每条均有平台范围，不能以“RF”标签省略型号核对。

- RF 需具体频段、封装、匹配/天线、叠层、地平面、禁布区、连接器和外壳环境；参考设计改动后要重新仿真/调谐/测量。
- 晶振和高速时钟属于敏感/噪声源双重角色：检查负载电容、回路短小、参考平面、邻近高 di/dt/高频网络、串扰和测量探头影响。
- 不能用 RF 的 50 Ω 规则给普通 GPIO、低速控制线或电源线自动定值，也不能把某芯片的晶振净空毫米数推广到不同型号。

### 电源、隔离和高压

已核读电源入口：`PWR-001..007`。隔离安规的当前标准正文及所有适用条款尚未取得；下列项目用于收集输入，不提供认证判定。

- 电源先按拓扑识别高 di/dt / 高 dv/dt 回路、反馈/Kelvin取样、热扩散、过孔与颈缩，再决定线宽、铜皮和层间路径。
- 隔离与高压必须由适用产品标准确定爬电/电气间隙、槽孔、涂覆、污染等级、材料组别、海拔和瞬态；PCB skill 不根据“电压×某固定倍数”生成安规距离。
- 隔离域两侧的信号/屏蔽/机壳耦合不能由布线器自行加跨域地过孔或电容；需要电路设计者批准并保留隔离验证证据。

## 3. 冲突裁决

当同一网络同时属于多个域，按 [研究方法](../research-method.md) 核查每个要求的效力与适用条件。先确认产品、安规、器件勘误、接口与项目硬约束能否同时满足，再用相符的参考设计、物理模型、仿真和测量比较候选布局。参考设计的名气或年代不自动压过已验证的物理证据；经验启发只用于排序。无法同时满足硬约束时，必须改变设计或保留未解决冲突，不能按来源类型机械选边。

不能用高速约束破坏隔离距离，不能用模拟分区破坏高速参考平面，也不能用电源铜皮破坏 RF/晶振禁布和回流。冲突无法通过已知资料裁决时，拆分候选方案，标记 `unknown`，请求仿真、测量或工程批准。

## 4. 覆盖边界

当前矩阵提供跨域路由和审查入口，不声称已经覆盖每一代 DDR、PCIe、MIPI、HDMI、USB4、100G 以太网、毫米波、安规产品或所有传感器。新增协议必须先登记规范版本、器件指南、层叠和验证工具，再新增规则卡；没有这些输入时不会用相近协议名称代替证据。
