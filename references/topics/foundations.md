## BAS-001：设计信号路径时同步确定回流路径

**问题与依据。** 不能把网名 GND 当成无阻抗的公共电流容器。信号互连的行为同时取决于信号导体和回流结构；在适用的交流/快速边沿条件下，参考铜面中的回流分布与减小信号—回流回路阻抗有关。参考路径出现缺口、开槽或不恰当绕行，会改变回路几何和电感，可能引起阻抗不连续、耦合及噪声问题。

**执行强度。** 对需进行信号完整性判断的网络，必须记录其参考结构是否已确定；保持适当连续回流属于带条件的设计建议。不能把本条直接变成所有网络必须满足同一数值距离的 DRC。

**适用条件与输入。** 用于分析单端互连、受扰敏感网络以及需要评估共模回流的结构。输入至少包括网络及实际铜形、层叠、相邻参考层/铜区域及其网络、信号边沿或相关频段、源端/负载返回连接。差分结构还要分别考虑差模与共模回路；低频/DC 电流分布、隔离边界和机壳/保护地连接不能直接套用“全部电流紧贴信号线下方”的描述。

**设计动作。**

1. 沿源端到负载检查信号和对应的返回连接，区分电路参考、机壳及保护地，不能只按文字网名认定等价。
2. 标出信号下方或邻近的实际参考铜区及其连续性。检查切缝、铜皮孤岛、开窗、连接器返回脚和焊盘附近瓶颈，优先选择可维持可解释回路的路由。
3. 遇到必须跨越的结构不连续，先考虑改变布局、走线或参考结构；保留该位置和理由，必要时进行提取、仿真或测量。

**验收与检查边界。** 每条受检查网络有可追溯的参考区域/返回连接记录；发现的跨缝、浮铜或无法识别的参考路径有修正或适用性分析。自动检查须读取真实铜形和连通性，截图只可辅助。几何检查没有发现缺口只能证明本检查覆盖的几何条件，不能证明串扰、EMI 或阻抗指标合格。缺少铜形、层叠或相关网络信息时标记未验证，不填“通过”。

**禁止泛化。** 不输出普适“100 kHz 以上都按某种路径”的阈值，不使用统一 3W 规则代替场分布判断，不因混合信号标签就自动割地。电磁分布随频率、结构和连接变化；来源示例并不是本项目完整模型。

**精确来源。** [7.1 Forget the Word Ground，网络第 1/21 页](https://www.informit.com/articles/article.aspx?p=2916283)；[7.13 Return Paths，网络第 13/21 页](https://www.informit.com/articles/article.aspx?p=2916283&seqNum=13)。两节的文本讨论信号/回流成对设计和返回结构不连续的影响；未基于图 7-20 的示例重新计算电流分布。

## BAS-002：信号换层时检查参考结构的转换

**问题与依据。** 信号过孔只保证信号导体换层，不能自动证明返回电流也能恰当地转换。换层前后的相邻参考结构及其连接决定返回路径；“每次换层都加地过孔”缺少参考网络判断，可能无效，甚至错误短接不同网络。

**执行强度。** 检查参考转换属于带条件的工程建议；不得短接原理图规定独立的网络或跨越隔离边界属于必须满足的连通约束。

**适用条件与输入。** 用于信号层改变、参考区域改变或连接器等处的返回路径转换。输入包括换层前后的信号层、邻近参考层/铜区、准确网络 ID、参考结构实际连通性、隔离域、边沿/频段及周围返回结构。仅“标称同电压”并不足以证明可以导通，例如两个地名或两个 3.3 V 电源可能属于不同域。

**设计动作。**

1. 先判断信号换层是否真的改变主要参考结构；不把“有过孔”直接等同于“必须新加某个器件”。
2. 若两个参考铜区属于同一个允许互连的电路网络，评估在信号转换附近提供相应的返回连接，例如连接同一 GND 网络的参考过孔。检查过孔实际接入相应铜区，不能仅凭外观相邻判定有效；具体距离和数量需按结构与性能要求确定。
3. 若参考结构属于不同网络或电位，禁止用导通过孔直接相连，尤其禁止把电源平面与地平面短接。优先考虑保持合适参考的路由/层叠；若转换不可避免，应按电路和隔离约束设计并验证相应回流耦合结构。
4. 跨参考电位的耦合不能简化为“固定加一个 0.1 µF 电容”。需要评估相关频段下的路径阻抗、安装电感、平面关系和允许的噪声/隔离要求；在快速边沿情况下，电容标称容量本身不能证明其有效。

**验收与检查边界。** 为受检查的转换位置记录“转换前参考—转换后参考—网络关系—实际返回结构—验证状态”。确认没有新增短路、隔离域被意外连接或参考过孔悬空。属于不同参考网络而缺乏可审查回流设计时标记未验证，不能以普通 DRC 通过替代。几何检查、连通性检查、提取/仿真和实测分别记录结果。

**禁止泛化。** 本条不给出通用过孔距离、数量、跨平面电容值或可接受噪声值；样章中数值例子的结构和模型不等于当前板子。不能将不同网络“可能通过电容交流耦合”理解为可以直接短接。

**精确来源。** [7.14 When Return Paths Switch Reference Planes，网络第 14/21 页](https://www.informit.com/articles/article.aspx?p=2916283&seqNum=14)。核读该页关于同参考网络过孔连接、不同电位平面间耦合、安装电感与高频地弹噪声的文本；该页图片公式和图中数值未独立核验，所以本条只采用定性结论。
