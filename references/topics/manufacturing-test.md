# 可制造性、装配与生产检验

本页把已核读的 TI QFN／SON 与 PowerPAD 原厂装配资料转换为工具无关的布局、工艺输入和验证要求。来源见 [厂商来源台账](../sources/vendor.json)，页码均为 PDF 文件页码。配合 [电源与热路径](power.md)、[多层板架构](multilayer-architecture.md)、[接口与隔离](interfaces-memory-isolation.md) 使用。

规则用于形成可交给 PCB 厂、装配厂及测试工程师核对的设计与工艺包。它们不构成完整 DFM／DFT、IPC 接受标准、可靠性鉴定或量产认证。厂商应用笔记中引用的 IPC／JEDEC 文件，不等于本知识库已获得并核读其全部标准正文。没有实际板型、器件版本、制造能力与样板证据时，检查只能输出 `unknown`、待验证事项和条件化方案。

**同板整合方式：** 先按每个器件实例生成其封装、焊盘、阻焊、钢网开口、散热和检验要求，再合并整板共享的表面处理、焊膏／合金、钢网厚度、回流窗口、双面装配顺序、板弯及测试夹具要求。例如，同板的 QFN 中心分窗与 PowerPAD 示例 1:1 开口可以分别有不同几何，但必须在共同钢网／焊膏和各器件可接受的实测回流条件下验证，不能简单取两者覆盖率的平均值。

**冲突处理：** 逐器件列出工艺允许窗口及来源，检查共同可行范围；没有共同范围时输出冲突清单和待工艺验证的方案，由制造／装配方评估局部钢网工艺、装配次序、器件或布局变更。全板通过不能由“每个器件套了一个推荐封装”推出，也不能用全板平均温度掩盖某个器件超温或焊点温度不足。

## MFG-001：焊盘、阻焊与表面处理按封装及工艺公差共同确定

- **条件／性质：** 新建、替换或缩小 QFN／SON／PowerPAD 封装；封装与制造输入门槛。
- **输入：** 器件完整订货型号、封装代号及尺寸公差、暴露焊盘尺寸和电气网络、pin 1 底部金属特征、PCB 铜蚀刻／阻焊对位与最小桥宽、表面处理平整性、装配定位能力和钢网能力。
- **动作：** 以目标器件当前机械图、推荐 land pattern 及装配厂能力建立铜、阻焊、焊膏三套独立几何；检查周边焊盘、中心焊盘和相邻导体在公差叠加后的间隙。存在 pin 1 底部金属时，按实际封装设置相应禁布区。替代料即使同为“QFN 同尺寸”，也重新核对焊盘、金属特征和电气定义。
- **检查方法：** 对照机械图核查引脚编号、方向、尺寸上下限及禁布区；由板厂核对阻焊开窗、桥宽、对位和表面处理，由装配方核对可印刷性和定位。保存封装来源／修订和已确认制造能力；未知公差不能以 EDA 默认值代替。
- **来源与定位：** `VENDOR-TI-SLUA271` pp.5-9 §§3.1-3.7，Figs.3-1 至 3-6；`VENDOR-TI-SLMA002` pp.4-7 §§2.2-2.3、Fig.7 与 Table 2。
- **限制：** SLUA271 对周边焊盘倾向 NSMD，SLMA002 的 PowerPAD 中心焊盘示例采用 SMD；两者不矛盾，也不能推出整板只能选一种。0.28 mm 焊盘、0.2 mm 间隙、阻焊扩展和 pin 1 示例禁布尺寸都不是跨封装默认；应用笔记中的尺寸起点须经目标器件与工厂确认。

## MFG-002：暴露焊盘及散热过孔同时满足电气、热与焊接要求

- **条件／性质：** 依靠底部暴露焊盘向 PCB 散热的封装；器件专用连接和工艺约束。
- **输入：** 焊盘电气归属、器件损耗与允许温度、热路径和层叠、中心焊盘焊接要求、过孔成品孔径／孔铜、所接铜层、填孔／塞孔／盖孔／覆盖工艺及表面处理、焊膏与允许焊点状态。
- **动作：** 将暴露焊盘按数据手册焊接到指定电气网络及热铜，不能默认全部接地。按热模型安排过孔与平面连接，并与装配厂一起处理焊料流失、困气和空洞风险；准确区分填孔、树脂塞孔、金属盖孔和阻焊 tenting 的实际工艺。对依赖直接导热的 PowerPAD 散热过孔，按专用指南检查其平面连接是否被 thermal relief 削弱。
- **检查方法：** 追踪焊盘至各层散热铜的实际连接，检查孔径／孔铜／数量／连接和制造图说明；结合 X 射线和热验证检查焊点、空洞及焊料流失。不能仅按过孔个数或导通证明散热有效，也不能只看顶层覆铜。
- **来源与定位：** `VENDOR-TI-SLUA271` pp.7-8 §3.4、Fig.3-4；`VENDOR-TI-SLMA002` pp.2、4-5、8-10 §§1、2.2-2.4、p.12 §3.1。
- **限制：** 0.3／0.33 mm 孔、约 1 mm 节距和示例过孔数量只属于所述工艺起点；SLUA271 明确并非所有应用都需要散热过孔。背面覆盖过孔可能困气，顶面覆盖也需考虑工艺；不自动规定全部 via-in-pad 都填孔或都不填。禁止 thermal relief 的结论限于上述导热路径，不能扩成全部焊盘禁止热焊盘连接。

## MFG-003：钢网开口按焊膏体积和封装离板高度设计

- **条件／性质：** 同一器件含小引脚焊盘与大暴露焊盘，或细间距器件共板；可印刷性及焊点形成约束。
- **输入：** 每个焊盘几何、钢网厚度和开口形状、开口面积／宽厚比、焊膏合金和金属体积分数、脱模性能、目标焊点与离板高度、贴装压力、同板其它器件和装配设备能力。
- **动作：** 铜、阻焊和焊膏层分别生成；联合选择钢网厚度、周边引脚开口与中心焊盘开口，必要时按该封装工艺分窗。估计实际焊膏体积及可释放性，验证中心和周边焊料能共同形成可靠接触，避免中心焊料过量使器件漂浮或不足造成连接／散热问题。
- **检查方法：** 用目标开口和厚度计算面积比／宽厚比并取得钢网供应方确认；通过印刷检查和装配样板核对焊膏转移、桥连、开路、器件高度和焊点空洞。报告印刷焊膏覆盖率、回流后有效焊接面积与空洞率时，分别写明定义和分母。
- **来源与定位：** `VENDOR-TI-SLUA271` pp.10-12 §§4.1-4.4、Figs.4-1 至 4-3；`VENDOR-TI-SLMA002` p.11 §2.5、Fig.11、p.12 §3.1。
- **限制：** SLUA271 的 QFN／SON 暴露焊盘给出约 50%-70% 印刷覆盖起点，SLMA002 的特定 PowerPAD／钢网／焊膏示例则给出 1:1 开口。不得择一作为所有封装默认，也不能把印刷覆盖率当作最终空洞验收值。0.125 mm 钢网、0.66 面积比、20% 缩孔或示例矩形开口均需工艺确认，不是通用布板规则。

## MFG-004：回流、湿敏、清洗和机械应力按实际板型验证

- **条件／性质：** 新板型、新封装、双面装配、返修或工艺变更；制造流程与布局共同约束。
- **输入：** 所有器件的 MSL／允许温度和回流次数、包装及存储暴露记录、焊膏推荐曲线、板厚／铜分布／热容量、器件密度、炉温设备、清洗剂／助焊剂、分板与夹具方式。
- **动作：** 在器件和焊膏允许窗口内为实际板型建立回流条件；在不同热环境和关键焊点位置测温，不以炉子设定值冒充焊点实温。把湿敏管理、双面回流及返修热历程纳入工艺；验证低离板高度封装下的残留、清洗与干燥，并在布局／拼板／夹具中控制板弯对薄封装的影响。
- **检查方法：** 保留测点、实测温度曲线、器件及材料批次／版本、装配次数和异常记录；确认局部峰温与时间窗口满足目标要求。通过实际工艺样板检查清洁残留及弯曲损伤；具体测试方法和限值由产品可靠性要求及材料供应方确定。
- **来源与定位：** `VENDOR-TI-SLUA271` p.4 §2.1、p.9 §3.7、pp.10、13-14 §§4.1、5.1-5.3；`VENDOR-TI-SLMA002` pp.13-15 §§3.2-3.3、4.1-4.2。
- **限制：** 原文中的示例升温速率、峰温、返修预热和“三次回流资格”只用于其器件及规定条件，不代表任意器件可返修三次。分类温度与实际焊接曲线不同；“no-clean”也不是所有产品、湿度或高阻电路无需清洁验证的保证。未核读完整 J-STD-020／033 现行正文，不自动生成烘烤和开放时间定值。

## MFG-005：隐藏焊点以适当检验方法确认，外观不能替代连接证据

- **条件／性质：** 底部焊点不可直接观察的 QFN／SON／PowerPAD；检验覆盖和验收定义约束。
- **输入：** 封装是否有可润湿侧翼、焊点缺陷类型、具体器件／产品验收要求、X 射线设备能力与测量方法、抽样或全检计划、热与电气验证要求。
- **动作：** 为隐藏中心焊盘和底部引脚选择可确认所需缺陷的检验方法；依需求使用 X 射线建立并监控装配工艺，区分桥连、焊料缺失、空洞与实际电气连接。侧面润湿外观按实际封装与接受标准评判，不因看不到侧面焊脚就判全部失效，也不因侧面外观好就判底部焊点合格。
- **检查方法：** 保存可追溯样板的图像、缺陷判读、设备设置和验收版本；明确空洞面积计算与区域，不把总空洞比例单独当作导热或寿命证明。必要时用电气测试、热测量或进一步失效分析核实 X 射线不能充分证明的连接状态。
- **来源与定位：** `VENDOR-TI-SLUA271` p.11 §4.4、pp.14-15 §5.4、Fig.5-3；`VENDOR-TI-SLMA002` p.12 §3.1、Figs.12-13。
- **限制：** 文中 50% 焊接面积／空洞建议与 JEDEC 测试板及器件热需求相关，不能成为所有产品的统一接受限值；局部空洞位置和机械可靠性也需项目验证。原文引用旧版 IPC-A-610D，且把 X 射线设备表述与 AOI 混用；本页不沿用这种设备分类，也不以旧版未镀侧边结论替代可润湿侧翼等新封装要求。检验不是寿命认证。

## MFG-006：布局预留生产测试入口，并用试产证据冻结设计与工艺

- **条件／性质：** 准备批量制造的 PCB／PCBA；项目 DFT 与试产放行输入门槛，本条包含明确标记的工程综合要求。
- **输入：** 项目故障覆盖目标、供电与保护限制、烧录／校准／功能测试流程、需要测量的网络、测试夹具接触和净空能力、信号／隔离约束、产品质量与可靠性验收计划、待发布设计和工艺版本。
- **动作：** 在布局阶段与测试工程师确认可接触的供电、返回、烧录、校准和关键观测入口；确定测试点、连接器或其它测试方式，避免探针碰撞及不受控供电。测试支路同时服从高速通道与隔离要求，不能为“每网有测试点”随意增加残桩。用实际板型试产验证封装、焊盘、钢网、材料和回流组合；改动后重新评估受影响的工艺和测试覆盖。
- **检查方法：** 核对每项测试需求到实际可访问对象、夹具空间及接受标准的映射，记录无法覆盖的故障；检查试产中的印刷、贴装、焊点、热／电气表现和异常闭环。将通过的封装库、PCB 制造文件、BOM、钢网／装配条件、测试程序和样板记录绑定到明确版本，缺失证据时仅标记已完成设计审查。
- **来源与定位：** `VENDOR-TI-SLUA271` p.3 的工艺开发与实验边界、p.4 Table 2-1、pp.13-15 §§5.1-5.4；`VENDOR-TI-SLMA002` p.12 §3.1 要求用实际工艺表征焊点与热效能。**这两份来源支持实际板型工艺验证与检验；本条测试入口、覆盖映射和版本冻结是本知识库的工程综合要求，不声称来源提供了完整 ICT／FCT／边界扫描标准。**
- **限制：** 不从应用笔记生成统一测试点直径／间距、抽样数量、良率或 Cpk 门槛；必须由目标工厂、测试方案和产品要求确定。没有试产、工艺能力与所需可靠性／法规证据时，不能标记“可直接大批量生产”“免人工复核”或“量产认证通过”。本页尚未覆盖全部 BGA／WLCSP、压接／通孔、板材 CAF、焊点寿命、环境试验、ICT／FCT 和行业产品标准。
