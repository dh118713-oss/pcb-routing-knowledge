# 多层板架构：层叠、参考、回流与制造

本专题把多层板的电气、热和制造问题放在同一个审查范围内。它不提供“固定四层板叠层”、固定线宽、固定过孔间距或“所有高速线都走某一层”的模板。层叠是器件、接口、供电、机械、阻抗、热路径和板厂能力的联合决策；每个结论都必须绑定具体板叠、材料和几何快照。

**定位与证据链。** `MLA-*` 是本库原创的架构审查组合入口，不是新增实验结论或已验证的制造规范。各入口只组合下文明确关联的已核读规则及其适用条件；它们没有独立的数值阈值。生成正式约束包时，拆成相应的 `BAS-*`、`HS-*`、`PWR-*`、`ANA-*` 或 `RES-*` 检查，使用底层规则的 `rule_id`、来源 ID 和精确章节，使来源台账中的 `supports` 能准确匹配。制造限值需引用本项目确实存在的板厂能力/订单要求；不得给 MLA 虚构来源支持关系。

本页的记录格式、版本一致性和提交证据要求属于[集成契约](../integration-contract.md)及[研究方法](../research-method.md)定义的工作流。尚未核读的书目只在文末“进一步阅读”中列出，不能支持本页动作或判据。

## 输入契约

正式审查至少需要以下数据；缺失项的状态必须使用接口定义的 `unknown`，并在 `reason` 或 `reason_code` 中记录 `needs_input`，不能从“几层板”“FR-4”“电源层”等名称猜测：

- 叠层表：层号、铜厚（成品值及公差）、介质厚度（成品压合值及公差）、材料/频率相关 Dk/Df、阻焊和表面处理。
- 参考结构：每段信号的相邻参考层、参考铜区所属网络、开槽/空洞/分割、平面边界以及跨区连接。
- 电路证据：拓扑、器件型号和封装、连续/RMS/峰值电流、边沿和带宽、回流路径、噪声/压降/温升预算。
- 机械与制造：板厚、板弯/应力要求、器件高度、连接器/天线/散热器、最小线宽/线距、孔径和环宽能力、盲埋孔/背钻/HDI能力、阻抗控制和测试 coupon 要求。
- 可验证几何：器件焊盘、铜皮、过孔（含盲埋孔深度和未连接段）、走线宽度、参考平面轮廓、颈缩、禁布区和板边距离。

## 规则

### MLA-001：先按功能和回流确定层叠候选，再谈线宽

- **性质：** 架构审查流程；验证现有层叠，或在其不满足项目条件时比较替代候选，不强制为每块板另造多套叠层。
- **动作：** 将高 di/dt 电源回路、敏感模拟、受控阻抗、高速换层、连接器/天线和散热路径标在候选层叠上；比较每条关键路径的相邻参考、换层次数、回流连接、铜厚和制造风险。不得先选一个“常用四层叠层”再强迫所有网络适配。
- **判据：** 每个候选有层号、铜厚、介质、参考网络和未解决冲突的记录；被选叠层的关键网络都有理由说明。
- **验证：** 叠层表和板级约束同一版本；阻抗、热、回流和制造审查引用同一成品数据。
- **来源与边界：** 组合使用已核读的 [HS-001/HS-002](high-speed-rf.md)（真实层叠、阻抗目标、参考层与回流）、[PWR-001/PWR-002/PWR-006/PWR-007](power.md)（功率回路、SW、载流与热路径）、[ANA-001/ANA-004](analog-emc.md)（功能分区与敏感网络耦合）及 [RES-002/RES-003](research-findings.md)（完整回路、平面结构和模型适用域）。各底层规则的器件、结构和频段边界继续适用；多个案例不能推导本板固定层叠。

### MLA-002：关键走线必须绑定连续且可识别的参考结构

- **性质：** 回流与阻抗约束；适用于边沿/频段使互连物理结构影响功能的网络。
- **动作：** 为每段信号记录相邻参考层/铜区及其网络；避免跨越参考开槽、孤岛或平面边界。信号换层时同时审查返回路径转换；同一允许互连网络才可评估返回过孔，不能把不同电源域或电源与地自动短接。
- **判据：** 走线投影到实际参考铜区后没有未解释的缺口；每个换层点均有返回结构或适用性说明。
- **验证：** 用层叠+铜形+网络连通性检查；没有参考平面几何时只能是 `unknown`。
- **来源与边界：** [BAS-001/BAS-002](foundations.md)，来源 `BOOK-003` 合法样章 7.13、7.14；以及 `HS-002`，来源 `VENDOR-TI-SLLA414` pp.6-11 §§3.4-3.5。仅采用条件化的回流结论，不提供固定过孔距离或桥接电容值；差模、共模及多参考面结构需分别判断。

### MLA-003：阻抗目标由接口和截面共同决定

- **性质：** 受控阻抗参数规则；不是“所有差分线 100 Ω”的默认值。
- **动作：** 由协议/器件指南确定目标单端或差分阻抗、容差和通道预算；用真实介质厚度、Dk/Df、铜厚、线宽、间距、阻焊和参考层调用适用的截面计算器或场求解器。将 BGA 扇出、焊盘、过孔和连接器纳入不连续性清单。
- **判据：** 线宽/间距/参考层来自指定截面和制造公差，阻抗目标及容差有来源；未完成求解时不输出已控阻抗。
- **验证：** 读取板厂叠层回传、阻抗 coupon/TDR 或通道仿真；DRC 通过只能证明几何规则覆盖的项目。
- **来源与边界：** 已核读的 `HS-001/HS-004`，来源 `VENDOR-TI-SLLA414` pp.3-5 §§2、3.1 与 pp.15-20 §§4.5-4.10；RF 专项可引用 `VENDOR-TI-SWRA640` p.20 §§4.10-4.11，但限其对应器件与结构。接口规范本身仍须按项目取得；本库未实现阻抗场求解器，不把应用笔记中的协议摘要视为当前接口的完整要求。

### MLA-004：电源/地平面布局同时满足电流、回流和压降

- **性质：** 电源完整性与热/压降联合约束。
- **动作：** 依据连续、峰值和纹波电流确定供电铜区和瓶颈；沿正向和返回路径分别预算压降与损耗。高 di/dt 回路优先缩小闭合面积并让相邻返回结构可追踪；敏感反馈和模拟参考不能共享未解释的大电流压降。
- **判据：** 每个关键电源段有电流、长度、成品铜厚、温升/压降预算和最弱截面；过孔、焊盘、连接器和颈缩已列入串联路径。
- **验证：** `dc-budget` 只能给均匀线段的压降下限；温升需要适用热模型或测量，平面阻抗/瞬态需要模型或测量。不能把大面积铜或 DRC 通过写成热/PI 通过。
- **来源与边界：** `PWR-001/PWR-002/PWR-003/PWR-006`，定位见 [电源专题](power.md)：`VENDOR-TI-SLYT614` PDF pp.1-4 及 `VENDOR-TI-SLVA773` pp.1-7 提供拓扑相关回路与取样讨论，`VENDOR-TI-SNVU591` pp.6-7、19、23 提供具有板型和气流条件的热/额定电流实例。上述资料不是通用载流公式；平面分布阻抗另按 `RES-003/RES-004` 的模型边界评估。

### MLA-005：参考平面跨层转换必须区分同网、同电位和不同网络

- **性质：** 换层回流和电气隔离约束。
- **动作：** 记录换层前后参考网络。若属于同一个允许互连的网络，可评估靠近信号过孔的返回过孔；若只是“电压相同”但属于不同网络，必须先确认架构与噪声边界；电源与地、隔离域或保护域不能被布线器自动桥接。不同参考电位之间应评估已允许的回流耦合路径、工作频带与安装寄生；本条不自动增加电容、磁珠或其它跨域器件。确需改变电路结构时，按适用电路、产品标准和现有工程授权处理。
- **判据：** 每个信号过孔都有“前参考—后参考—网络关系—实际返回结构—验证状态”；无证据时 `unknown`。
- **验证：** 检查网络连通性、过孔接入层、反焊盘和参考平面开口；必要时做 SI/PI/EMC 模型或实测。
- **来源与边界：** `BAS-002`，以及 `HS-002`。不能把“每个换层加地过孔”或“跨平面放一个 0.1 µF”写成通用硬规则。

### MLA-006：盲孔、埋孔和背钻是制造与电气的联合选择

- **性质：** 高密度/高速互连结构决策。
- **动作：** 按实际需求选择孔结构：密度/扇出、通道不连续或其它经说明的功能需求可以触发评估，不能要求每项都同时有收益。由板厂确认可制造的起止层、成品孔径、纵横比、镀铜、捕获盘、反焊盘、残桩和公差；不同孔结构改变电连接和可能的热路径，需检查对应任务，不能只按“减少残桩”决定。
- **判据：** 工艺能力确认了每种孔结构；关键过孔的残桩/不连续已计算或仿真，测试 coupon 与量产可检验性已定义。
- **验证：** 读取板厂 DFM/能力回传和截面报告；高速网络用适用模型/TDR/通道仿真复核，功率/热过孔用热和可靠性证据复核。
- **来源与边界：** `HS-004`，来源 `VENDOR-TI-SLLA414` pp.15-20 §§4.5-4.10，支持过孔/残桩的通道审查；涉及热路径时关联 `PWR-007`。盲埋孔工艺、可靠性、尺寸和可检验性来自本项目板厂文件，本库没有已核验的通用 HDI 制造数值，不从未读标准生成孔径、过孔电流或背钻深度。

### MLA-007：热路径不能被层叠或过孔假设掩盖

- **性质：** 热设计和可靠性约束。
- **动作：** 标出发热器件、铜扩散区、热过孔、内层平面、散热器/机壳和环境边界；区分电流过孔、热过孔和 EMI/回流过孔的任务。检查焊盘下过孔、孤立铜、板边和连接器瓶颈的实际热路径，不以“铜皮连通”代替温升分析。
- **判据：** 功耗、环境、目标温升、铜厚、热导路径和安装边界有数值或明确未知项；热源之间的耦合列入检查。
- **验证：** 采用适用热仿真、热像/热电偶或样板温升测试，并记录负载、环境、测点和误差。无热证据时结论为 `unknown`。
- **来源与边界：** [PWR-007](power.md)，来源 `VENDOR-NEXPERIA-AN90003` pp.2-4、10-14、21-23，§§2、2.3.2-2.3.4、3.1.1、3.2.1；补充 `PWR-006` 与 `VENDOR-TI-SNVU591` pp.7、19、23。Nexperia 的 LFPAK 几何、铜面积与过孔示例不可直接迁移为任意封装参数；导体温升与器件结温是不同检查，均须确认实际边界条件。散热器的 EMI 影响另见 `RES-005`，不将其辐射模型当作热模型。

### MLA-008：制造可行性必须回读到电气约束

- **性质：** DFM 与电气性能的联合约束。
- **动作：** 在定稿前核对板厂最小线/距、铜厚公差、孔径/环宽、阻抗容差、叠层压合、盲埋孔/背钻、阻焊桥、板边和表面处理。制造修正或公差影响截面时，重查其是否仍在阻抗、压降、温升和间距模型的已评估范围内；超出范围的项重新求解，不能因修改已被板厂接受就视为电气通过。
- **判据：** 约束引用当前板厂能力文件或订单能力；超出能力的结构有批准的替代和再验证计划。
- **验证：** 读取板厂反馈、阻抗 coupon/截面报告及最终 Gerber/钻孔数据；版本改变后重新绑定审查，不沿用旧板截图。
- **来源与边界：** 这是 [集成契约](../integration-contract.md) 的项目输入/版本工作流，结合 `HS-001/HS-004` 对截面与通道结构的检查和 `PWR-006/PWR-007` 对有效铜形/热路径的检查。具体制造判据仅能引用真实板厂能力与本项目订单要求；本条不是独立的 IPC 合规规则。

### MLA-009：板边、连接器、散热器和机械开口属于电气结构

- **性质：** EMI/回流/热/可靠性联合审查。
- **动作：** 把连接器、线缆、板边、螺钉孔、开槽、散热器、屏蔽罩和天线禁布区加入层叠审查；检查参考平面在这些位置是否被切断、回流是否被迫绕行以及散热铜是否形成意外辐射结构。机械变更后重新审查关键路径。
- **判据：** 机械约束图和 PCB 铜形/层叠同一版本；跨板边/连接器的信号和返回路径可追踪。
- **验证：** 必要时做近场/线缆共模测量、EMC 预扫、热分析或全波仿真；DRC 不能证明机壳、线缆或散热器耦合合格。
- **来源与边界：** [RES-002/RES-005](research-findings.md)：`PAPER-HUBING-2013-PERFORMANCE` §II.3-II.4 p.202、§III.1-III.3 pp.203-205，以及 `PAPER-HE-2011-HEATSINK` §§I-V，PDF pp.1-4；回流断口关联 `BAS-001/HS-002`，天线结构限于 `HS-006` 实际支持的器件/频段。机械特征是否形成显著耦合需依实际电尺寸和源判断；不是所有螺钉孔都自动不合格。外部案例与本项目实测分别记录。

## 交付格式

多层板审查输出至少包含：

1. 叠层快照（层号、铜厚、介质、材料、公差、版本）；
2. 每个关键网络的参考层和返回结构；
3. 电源/热/制造瓶颈表；
4. 盲埋孔/背钻和阻抗结构的输入与验证状态；
5. `pass | fail | unknown | not_applicable` 逐项结果及证据定位；缺少输入时用 `unknown` 并在理由中写 `needs_input`；
6. 未解决冲突、需要上游布局或板厂确认的行动项。

`DRC 通过`、`线宽已设置`、`过孔数量足够`、`有完整地平面`都只能作为某项局部证据。没有真实层叠和几何时，本专题可以做架构审查和缺口清单，但不能声称阻抗、回流、热、制造或 EMC 已通过。
